Vì sao cần file cookies.txt?

Trình phát video chạy độc lập trên máy tính không thể tự đăng nhập tài khoản Facebook hay Bilibili của bạn. File cookies.txt (chuẩn Netscape) đóng vai trò là "chìa khóa phiên duyệt web", cấp quyền để ứng dụng trích xuất luồng video chất lượng cao nhất mà tài khoản của bạn được phép xem.

Cách 1: Xuất cookies bằng tiện ích mở rộng (Khuyên dùng)

Đây là phương pháp đơn giản, an toàn và trực quan nhất. Bạn chỉ cần cài một tiện ích mở rộng mã nguồn mở (Open Source) chạy hoàn toàn cục bộ trên trình duyệt.

Tiện ích khuyên dùng (Get cookies.txt LOCALLY): 🌐 Cài đặt cho Chrome / Edge / Brave / Cốc Cốc 🦊 Cài đặt cho Mozilla Firefox
  1. Cài đặt tiện ích mở rộng

    Nhấp vào liên kết ở trên tương ứng với trình duyệt bạn đang sử dụng và nhấn "Thêm vào Chrome" (hoặc Firefox).

  2. Đăng nhập trang web cần lấy cookie

    Mở tab mới trên trình duyệt và đăng nhập vào tài khoản của bạn (ví dụ: facebook.com hoặc bilibili.com).

  3. Xuất file cookies.txt

    Trong khi đang ở trang web đó, nhấp vào biểu tượng tiện ích Get cookies.txt LOCALLY trên thanh công cụ → Nhấn nút "Export" để tải file về máy tính.

    Đặt tên gợi nhớ, ví dụ: facebook_cookies.txt hoặc cookies.txt và lưu vào thư mục an toàn (như Documents hoặc thư mục cài app).

Cách nhập (Import) file vào FB Video Watcher

  1. Mở hộp thoại Cài đặt & Cấu hình

    Trong cửa sổ FB Video Watcher, nhấn tổ hợp phím Ctrl + , (hoặc nhấp chuột phải vào màn hình video → chọn Cài đặt & Cấu hình...).

  2. Chọn file cookies vừa xuất

    Tìm đến mục "File cookies:" → Nhấn nút "Chọn file..." → Trỏ đến file cookies.txt bạn vừa tải về ở bước trên.

  3. Lưu cài đặt và thưởng thức

    Nhấn nút "Lưu cấu hình" ở góc dưới hộp thoại. Giờ đây bạn có thể dán bất kỳ liên kết video nào để xem ngay lập tức!
